2.1 Security Measures & Purposes

  • Physical Security: Access control vestibules (mantraps), badge readers, biometric scanners, CCTV, motion sensors, bollards, cable locks.
  • Logical Security: Principle of Least Privilege, Access Control Lists (ACLs), Multi-Factor Authentication (MFA / OTP).
  • Management Tools: Active Directory (Group Policy, OUs, login scripts, folder redirection), MDM (Mobile Device Management).

2.3 Malware 7-Step Removal Procedure

  1. Identify and investigate symptoms.
  2. Quarantine infected system.
  3. Disable System Restore.
  4. Remediate / Update anti-malware software.
  5. Scan and remove infection (Safe Mode).
  6. Enable System Restore & create new point.
  7. Educate the end user.

2.4 Social Engineering & Threats

  • Phishing / Vishing / Whaling: Deceptive emails, phone calls, or targeted executive attacks.
  • Tailgating / Impersonation: Following someone through a door; posing as tech support.
  • Evil Twin: Rogue wireless AP intercepting traffic.

2.5 & 2.6 Workstation & SOHO Security

  • Data Encryption: BitLocker (Windows), FileVault (macOS).
  • SOHO Router Config: Change default credentials, disable SSID broadcast, enable MAC filtering, configure port forwarding.

2.7 Browser Security

  • Certificates: Verify valid SSL/TLS certificates and HTTPS.
  • Extensions & Privacy: Restrict browser extensions to trusted stores, clear cache/cookies regularly.
