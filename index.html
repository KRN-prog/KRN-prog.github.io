1.1 Windows Features & Editions

EditionMax RAMCPU SocketsDomain Join / RDP Host

Workstations6 TB4Yes / Yes (ReFS, NVDIMM)

32-bit vs 64-bit: 32-bit = Max 4 GB RAM. 64-bit = Up to 6 TB RAM.
BitLocker vs EFS: BitLocker = Full volume encryption. EFS = Individual file/folder encryption on NTFS.

1.2 Installation & Upgrades

  • In-place upgrade: Preserves files, settings, and apps.
  • Clean install: Wipes drive; requires reinstalling applications.
  • PXE Boot: Network-based OS deployment using NIC boot ROM.
  • Unattended (`autounattend.xml`): Automates setup prompts using Windows SIM.
  • Image Deployment: Sysprep removes system-specific SIDs before capture; DISM services WIM images.
  • MBR vs GPT: MBR = Max 2 TB, max 4 primary partitions. GPT = Max 9.4 ZB, up to 128 primary partitions (requires UEFI).
  • Filesystems: FAT32 (4 GB file limit), exFAT (Flash drives, cross-platform), NTFS (Permissions, encryption, compression), ext4 (Linux native), CDFS (CD-ROMs).

1.4 Admin Tools & 1.5 Settings

  • services.msc: Start, stop, and set startup types for services.
  • devmgmt.msc: Device Manager (Driver updates, rollbacks, hardware status).
  • diskmgmt.msc: Disk Management (Partition, format, extend, shrink).
  • compmgmt.msc: Computer Management (Combines MMC snap-ins).
  • secpol.msc: Local Security Policy (Password complexity, lockout threshold).
  • msconfig: System Configuration (Selective startup, boot options, service toggle).
  • UAC Levels: Always notify (strictest), Notify only on app changes (default/dim), Notify without dimming, Never notify.
  • Indexing Options: Controls search indexing locations for fast file retrieval.

1.6 macOS Utilities

  • Finder: Graphical file manager (equivalent to Windows File Explorer).
  • Spotlight: System-wide search tool (Cmd + Space).
  • Time Machine: Automatic incremental backup system.
  • Disk Utility: Format, partition, and run First Aid on drives.
  • Force Quit: Force stop unresponsive apps (Cmd + Option + Esc).
  • Keychain Access: Password and certificate management vault.
  • Activity Monitor: Real-time process resource usage (equivalent to Task Manager).
