Domain 1.0 — Operating Systems

  • Editions & Limits: 32-bit = Max 4 GB RAM. Home = 128 GB RAM, no Domain Join, no RDP host, no BitLocker. Pro = 2 TB RAM, Domain Join, BitLocker. Workstations = 6 TB RAM, 4 CPUs.
  • Installations: Unattended uses autounattend.xml. Repair install replaces OS files while keeping apps/data. Sysprep strips SIDs before image capture.
  • CLI Repairs: sfc /scannow (system files) → if fails, run dism /online /cleanup-image /restorehealth. chkdsk /f /r (fixes FS errors + bad physical sectors).
  • Bootrec: /fixmbr (MBR), /fixboot (boot sector), /rebuildbcd (rebuilds OS boot list).
  • Networking & Shares: Public profile hides PC (coffee shop); Private enables Network Discovery & file sharing. Mapped drives pointing to old servers must be remapped to new UNC paths.
  • Linux & macOS: su (switch session to root) vs sudo (single root command). chown user:group file. ps aux (static snapshot) vs top (live). macOS Activity Monitor = Task Manager.

Domain 2.0 — Security

  • 7-Step Malware Removal: 1. Identify symptoms → 2. Quarantine → 3. Disable System Restore → 4. Update anti-malware → 5. Scan & remove (Safe Mode) → 6. Enable System Restore & create point → 7. Educate end user.
  • Password Attacks: Dictionary = uses a pre-compiled word list (with symbol variations). Brute-force = tries all character combinations. Rainbow table = precomputed hashes.
  • SOHO & Wireless: Disable WPS (8-digit PIN vulnerable to brute-force). Always change default router admin credentials. Use WPA2/WPA3 with AES.
  • Physical & Mobile Security: Server rack locks protect shared colocation servers. Mobile theft protection = Full device encryption + Remote wipe.
  • Data Destruction: Degaussing = fastest method to erase massive quantities of magnetic HDDs using a strong magnetic field.

Domain 3.0 — Software Troubleshooting

  • Mobile App Issues: Single app crashing → Clear app cache & data first. Slow phone right after installing a new app → Uninstall, reboot, reinstall.
  • Post-Update Crashes / Static: Screen static or blank boot right after security patches/updates → Boot into Safe Mode and Rollback the driver or recent update.
  • Slow Boot: First step = Disable unnecessary startup programs via Task Manager (Startup tab) or msconfig.
  • Browser Redirects / Foreign Language: If anti-malware is clean, check and remove unauthorized Proxy Servers in browser settings.
  • Windows Update Service Fix: After re-registering Update DLLs (regsvr32) and restarting the service, always Reboot the PC.

PII vs PHIPII = Personal Identifiable Info (SSN, DOB, email). PHI = Protected Health Info (medical records).
  • Server Room Environment: Ideal humidity = 40–60%. High humidity (>80%) causes corrosion; low humidity causes ESD (static discharge).
  • Screened Subnet (DMZ): Place public-facing servers (FTP/Web) in a screened subnet to isolate them from the internal LAN.
  • Virtualization DR: Virtual machines have less downtime than physical servers during disaster recovery (fast snapshots/cloning, hardware-independent).
